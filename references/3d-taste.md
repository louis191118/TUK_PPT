# 취향 기록 → 규칙 (숨길 발표에서 사용자가 직접 고친 말)

움직임·3D 취향은 말로 물으면 답이 안 나온다. 숨길 덱을 만들며 사용자가 **화면을 보고 나서** 한 말을 그대로 모으고, 그 말이 만든 규칙을 옆에 적었다. 새 주제에서도 이 규칙을 기본값으로 쓰고, 처음 보여 줄 때 이 수준에서 시작한다(decisions.md, 2026-11-17~18).

| 사용자 말 (원문) | 규칙 |
|---|---|
| "지도 3D모션이 계속 반복되도록 하면 좋겠어" (표지) | 머무는 장(표지·마무리)은 반복 모드. 설명 장은 단계 모드 |
| "경로가 막 없어지는건 정신없어 약간 물 흐르듯이 부드러워야 해" | 그렸다 지웠다 하지 않는다. 바뀌는 것은 이어서 흐르게 |
| "경로가 사라지는게 아니라 이미 있는 부분에서 색만 그라데이션 처럼 바뀌는거야" | 반복 모드에서 형상은 고정, **색 띠만 흐른다** |
| "건물과 지형이 부드럽게 움직이게 … 잔잔한 파도처럼" | 바탕의 움직임은 아주 작고 느리게(진폭 0.2~0.3 장면 단위, 6~7초 주기), 위로만 |
| "물결을 바닥의 네모칸이 하나의 피스가 되어 움직여야 해" | 휘는 메시 대신 **의미 있는 단위(칸·모듈)가 통째로** 움직인다 |
| "조금 더 잘 보이면서 튀지 않게" (경로 그라데이션) | 강조 띠는 같은 색 계열의 밝은 쪽, 회색 띠는 푸른 회색. 새 색을 들이지 않는다 |
| "첫페이지 경로 그라데이션 강하게 해서 더 잘 보이게" | 띠가 안 보이면 띠를 더 세게가 아니라 **띠 밖 바탕을 살짝 어둡게**(대비) + 띠 폭 |
| "첫페이지 물결 아주 조금 더 세게" | 조정은 작게(0.22 → 0.27, 7 → 6.4초). 한 번에 크게 바꾸지 않는다 |
| "모양은 달라지지 않고 모션만 발표에 도움되게 … 필요한 것만" | 애니메이션의 **마지막 프레임 = 승인된 정지 화면**. 모션은 설명 순서를 보이는 데만(막대가 자람, 기준선이 그어짐, 숫자가 세어 올라감) |
| "8페이지 칸 애니메이션 디벨롭해줘" | 단위가 쌓이는 장은 쌓이는 순서 그대로(달력처럼 열 → 행, 칸마다 20 ms·9 ms 지연), 숫자는 칸과 같은 박자로 |
| "첫장에 … 우리 앱 디자인 언어 … 각인시키고 싶어" | 표지에 본편과 **같은 3D 세계**(같은 도시·같은 길)를 두고, 마무리에서 다시(수미상관) |
| "해부는 … 3D에셋 소개할 일 있을때 쓰려고 만들어본거야" | 에셋 소개는 본편 밖(숨김 장·탐색 장)도 선택지. 조사·제작 과정을 남겨 다른 물건에 다시 쓴다(asset-research.md) |
| "에셋은 highquality 오픈소스 최대한 활용하게" | 모델·소품·질감·환경광은 고품질 오픈소스(CC0·CC BY) 그대로 → 다듬어서 → 직접 만들기는 마지막(3곳 이상 뒤진 기록). 상자·원통 조립 소품으로 시작하지 않는다 |
| "프로젝터용 대비 상향" (색 한 단계 진하게, 흐림 .25 → .4) | 3D 라벨·리더선도 토큰을 쓰므로 함께 진해진다. 3D 안 색을 하드코딩하지 않는다 |

## 시작 수준 (처음 보여 줄 때부터)
- 장면은 흰 바탕에 틀 없이 떠 있다. 가장자리는 바탕에 녹는다.
- 카메라는 단계마다 정한 자세로만, 1초 ease-in-out. 자유 회전·자동 회전 없음(탐색 장 유휴 회전만).
- 경로·흐름은 차 주행처럼 출발·정지(`ease.drive`), 같은 속도.
- 라벨은 그 대상이 화면에 "도착한 뒤" 나타난다(경로 머리가 라벨 자리를 지난 뒤).
- 금속 반사·블룸·피사계 심도·파티클·네온·글래스모피즘 없음. 실물 장면의 빛은 스튜디오 판 조명 하나.
